# 先搭框架、优先前后处理与参数化

2026-10-01 用户确认的实施方向。沿用 [顶层设计](ARCHITECTURE.md) 的模块边界，机器计划的 `delivery_batches` 是下面交付批次的对应记录。以工程任务为单位补齐，再细化菜单；不是先实现所有框架对象才能做业务，也不是按按钮数量推进。

| 批次 | 交付对象 | 优先内容 | 本次边界 |
|---|---|---|---|
| B0 共用框架 | 能组合、检查并执行现有操作 | 模块归属、统一路由、参数与依赖预检、结果合同、质量门槛、任务证据 | 已接入现有工作流；完整 ModelRef、按需大模型访问仍需补 |
| B1 前处理 | 可保存、重开、核对的模型 | 部件/区域/基本拓扑选择，常用变换、节点/单元编辑，合并、法向、编号与质量检查 | 本次贯通部件选择→平移→Hex8质量→保存重开及参数复用；不等于全部网格编辑 |
| B2 后处理 | 数据、图片与动画可核对的工程结果 | 原生曲线/应力/常用历史量、相对位移、力—位移/应力—应变、能量、曲线图/云图保存、动画导出 | 已有原生提取→工程曲线→单曲线PNG及连续MP4导出；更多变量、多曲线和云图语义一致性继续推进 |
| B3 自动参数化 | 能重复用于新工况的流程 | 录制、参数绑定、明确工况表、独立执行、质量断言、结果汇总 | 本次支持1–20组显式参数顺序执行；不含优化器、任意分支及崩溃续跑 |
| B4 版本交付 | 有明确支持范围的可用包 | 三条流程联调、安装/Skill路由、正反例和公开支持矩阵 | 三条核心流程通过后发布；不等待全部菜单覆盖 |

B1、B2、B3 共用 B0，各批次按依赖交错推进，避免长期只扩展前处理。优先顺序由是否补上完整任务的缺口决定；已经具备的操作直接复用。

## 下一步选择原则

最新 B2 增量：[原生媒体输出](NATIVE_MEDIA.md) 已通过完整 MP4 时间线、单曲线 PNG、数值读回与录制回放验收，并新增显式字段/状态/层/单位的原生 CSV 与云图、完整自定义场动画覆盖检查。非平凡验证目前以实体应力和节点位移为主，壳层/失效语义仍需扩展。B1 新增[大模型分页读取](MODEL_SCALE.md)，超过30万实体单元的私有模型读取与原生 Mises 导出通过；旧整模选区/编辑的20000限制仍待改造。任意动画起点/步长、GIF、多曲线继续按下列业务顺序推进。

1. 前处理先处理模型/选区访问与常用编辑的完整链，特别是拓扑选择、节点/单元引用更新和大模型边界。
2. 后处理优先完成“提取曲线→工程计算→保存曲线图和数据”，同步补常用数据库、层/积分点、有效实体和云图元数据。动画导出也是核心输出，需核对状态范围、步长、帧率、帧数、时间顺序和可播放性。CSV成功不算原生曲线图导出成功，动画播放不算动画文件导出成功。
3. 参数化直接复用前两条流程，支持改变模型、选区、变换量、阈值、面积和标距等显式参数，不隐式决定物理条件。
4. 原生XYPlot细项、多窗口排版、低频菜单、复杂模板、旧版本和无GUI适配逐批扩展；几何/CAD生成网格和求解调度保持后排。

## 进度口径

记录“框架接入 / 实现 / 限定原生验收 / 完整流程验收”，同时给出剩余边界。工具数、测试数、来源条目数不作为功能覆盖率。23项待做是此前清单快照；本次参数迭代进入部分实现，不能据此宣称自动化模块完成。
