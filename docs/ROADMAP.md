# 常用功能建设路线

目标版本：4.8、4.10、4.13。4.11不在当前范围。未来版本按同一矩阵加入，不自动宣称兼容。

当前完成与缺口以[覆盖矩阵](COVERAGE.md)为准。PyDYNA六个文档板块的实际转化见[集成分析](PYDYNA_INTEGRATION.md)。以下是持续建设方向，不是已完成功能清单。

## 已开始的基础层

任务目录与日志、MCP/CLI、cfile/Python/SCL入口、模型查询、基础壳网格、图片验证、数值后端、版本选择、来源检索和工作流Skill。

## 接续能力

1. **数据语义与结果**：状态时间、ID映射、六分量应力/正确Mises、积分点、坐标配置、失效实体、历史变量、CSV与云图对应验证。
2. **前处理**：形状网格、球体/圆柱/实体、选择、集合、变换和阵列；壳实体转换、网格质量、保存读回。
3. **分析设置**：材料、截面、边界、载荷、初速、接触和输出控制；以官方球撞板全流程验收。
4. **常用后处理**：受控色标/平均/层、批量图片/动画、截面、矢量、轨迹、力—位移、多工况比较。
5. **领域流程**：随机骨料、SPH、碎片、虚拟应变计及实验对比，分别建立数据基准。
6. **高级操作**：几何修复、中面、复杂网格、持久GUI会话；各自验证事件循环、状态恢复和兼容性。

## 能力完成条件

每一项都需要：来源 → 参数与前置条件 → 适配器/命令配方 → 失败测试 → 指定构建真机测试 → 模型/数值/图像验收 → Skill路由。

功能覆盖以任务清单衡量，不以工具数量、命令表行数或README长度衡量。发现原生程序崩溃时记录构建、输入身份、命令、退出码及日志，拒绝伪造成功或悄悄用另一后端冒充原生处理。
