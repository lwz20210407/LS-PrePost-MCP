# A01：单命令执行与请求日志

2026-10-05，归属 A01；I02 六个语义合同字段不变。

`run_script(language="command", context="batch"|"session")` 返回 JobResult。
批处理经 BatchEngine；会话仅在指定进程执行。打开模型走已有托管打开操作，
返回请求原文，并在原生日志中保留实际暂存路径。其它语言由 A02–A05 接入。

会话增量日志在相关回执到达后、释放请求锁之前复制。返回原始日志文件及
SHA256、来源偏移、解码是否有损；长日志通过文件交付。已有失败不会因日志
缺失被降为 unverified。无效命令和输出文件无法打开均明确失败。

原生相对路径不跟随 Python 的 cwd；4.13 队列实测中图片落入上次模型目录。
声明的输出文件名按完整参数 token 绑定到新请求目录的绝对 Windows 路径，
同时记录 requested_source 与 executed_command。关键字保存的正斜杠盘符路径
会触发 `templsppfile_` 前缀错误，使用 Windows 反斜杠；不通过移动旧产物补救。
批处理保持隔离 cwd 和相对输出文件名。

初始节点选择、单命令、模型快照在会话同一锁内执行，防止中间插入另一个
请求。快照只是原生模型存档；工程质量仍需单独检查。选择/显隐读回最多
10000 项，超过时返回空缺标记，不伪造完整枚举。
