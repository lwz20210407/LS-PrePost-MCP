# A10：结构化字段查询的漏查修复

2026-10-06，从已构建的公开字段索引机械抽取 100 个确定存在的“关键字＋字段”组合，
调用 keyword_fields(..., limit=1)。抽样按数据库去重后的 66110 个组合排序，每隔 661 个取一个，
取前 100 个；没有用自然语言留出题选样或调参。

旧实现先全文排序截断，再过滤字段，导致 6 个已存在字段返回空。
现在按字面关键字前缀、字段或别名先筛选，再应用 limit；完整关键字优先，
随后按关键字、卡片、选项、列位稳定排序。下划线与斜线按普通字符处理。
私有过滤仍在 limit 之前，来源、版本和提供者验证归属继续保留。
