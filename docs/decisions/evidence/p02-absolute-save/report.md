# P02/P11：拒绝失联的外部依赖修改副本

主干 `745e3f2` 上复现：主文件通过绝对 `INCLUDE_PATH` 引入材料，或绝对 Include 父文件再相对引入
材料。修改材料后 save_as 可能写出新材料文件，但主文件仍指向原外部依赖，重载读取旧值。
原有绝对路径保护只检查直接子文件，遗漏搜索目录和外部父文件的后代。

现在将这些不可随根模型迁移的依赖明确作为 external_unchanged；有修改时在任何输出文件写入前拒绝。
绝对父文件中通过 main-dir 回退解析的子文件仍随主文件迁移；不把这种回退误判为外部固定依赖。
外部父文件的 opaque 资产同样保持外部，普通相对 opaque 资产仍逐字节复制。输入始终不改。

三个反例在旧主干失败；最终相关测试 58 passed，涵盖原始文件保真、相对搜索目录正常修改重载、
main-dir 回退、opaque 字节复制、外部修改在 MCP 返回 failed 且无 verified 产物。
这是纯 Python/L1 回归，没有启动原生进程。

本次修复防止“写了但重开没用到”的成功结果，不提供自动绝对路径重写或绕过非覆盖输入约束。
P02/P11 保持 partial。可移植迁移需要显式改写路径卡，属于后续已登记缺口。
