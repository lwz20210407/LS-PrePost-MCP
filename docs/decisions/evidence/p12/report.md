# P12 运动副：R11 验证与真实模型检查（2026-10-06）

求解器：LS-DYNA R11.1.0 SMP 双精度（Ansys 许可）。逐项数值见 [evidence.json](evidence.json)。验证用的算例生成脚本和求解输出在仓库外。

## 1. 解析解算例

每个算例都先通过 `edit_deck` 的 `add_joint` 写入运动副，再用 R11 求解，最后与解析解对比。单位制为 mm-t-s，重力 9810 mm/s²。

| 算例 | 运动副 | 结果 |
|---|---|---|
| 单摆，5° | 转动铰 | 周期 0.73541 s，解析解 0.73309 s（+0.32%，即 R11 集中质量惯量比连续体大的部分）；振幅 5.0002°，不衰减；绕轴半径漂移 0.020 mm |
| 同上，节点对间距 100 mm | 转动铰 | 轴向漂移从 0.32 mm 降到 0.10 mm（间距 20 mm 时为 0.32 mm） |
| 锥摆 | 球铰 | 到铰点距离漂移 0.015 mm（摆长 200 mm），离开原平面 11 mm |
| 绕杆轴自旋 5 rad/s | 球铰 | 0.5 s 转过 143.234°，自由转动应为 143.239° |
| 同上 | 万向节 | 0.0°：扭转被锁住 |
| 30° 斜面滑块 | 移动副 | 沿轴位移 24.520 mm，解析解 24.515 mm；横向漂移 0.0005 mm，转动漂移 0.0003 mm |
| 同上，加 20 rad/s 自转 | 圆柱副 | 沿轴位移 24.520 mm；自转 1.9996 rad，解析解 1.9996 rad |
| 面内重力加面内初速度 | 平面副 | dx −49.040 mm（解析解 −49.030 mm），dy 19.996 mm（解析解 19.996 mm），法向位移 0 |
| 30° 倾斜杆受重力 | 锁定 | 末端最大位移 0.46 mm；不锁定时自由摆动的量级为 441 mm |
| 以 2π rad/s 驱动 | 转动电机 | 默认罚函数下 0.5 s 只转 1.73 rad（目标 π）；`*CONTROL_RIGID` LMF=1 时 3.14147 rad |
| 以 100 mm/s 驱动 | 移动电机 | 位移绝对值 9.979 mm，解析解 9.998 mm |
| TFAIL = 0.3 s | 转动铰 FAILURE | 失效前位移 0.03 mm；失效后下落 196.256 mm，自由落体 196.2 mm |
| 弹性杆顶面做节点刚体（蜘蛛） | 转动铰 | 周期 0.73538 s，与刚体解析解相差 +0.31%；振幅 5.00007° |

所有输出模型的 check_model 结果均为 0 错误。

## 2. 官方示例重建对比

做法：删除原有运动副，用 `add_joint` 按原来的 JID、几何、两侧刚体、RPS、DAMP、电机和 FAILURE 重新建出来。原版和重建版加上相同的输出，各自用 R11 计算，再比较结果。

| 示例 | 运动副 | 动能最大相对差 | 其他 |
|---|---|---|---|
| dynaexamples `constrained.joint_planar.k` | 平面副 | 0 | 节点位移差 0 |
| dynaexamples `constrained.joint_revolute.k` | 转动铰（带限位刚度） | 0 | 位移差 2.7e-20 |
| J. Day `revo-stiff.k` | 转动铰（刚度） | 0 | 位移差 0 |
| J. Day `translat.k` | 移动副 | 0 | 位移差 0（第三对节点按原位置给出，`third_point`） |
| `EXP_SC_JOINT_REV_TRANS.key` | 转动铰 + 移动副 | 9.3e-7 | 运动副力最大差 0.043，最大值 6.90 |

`translat.k` 的第三对节点本来就不垂直于移动方向（原文件注释也是这么说的）。如果改用默认的垂直布置，动能差会到 59%，所以加了 `third_point` 参数，可以按原位置给出。

## 3. 真实模型检查

一共检查了 80 个使用 `*CONSTRAINED_JOINT` 的 deck，读出 938 个运动副，没有崩溃。
- 公开语料 33 个，含 236 个运动副，名单见 evidence.json；
- 用户本地案例 47 个，含 702 个运动副，只计数量。

开发过程中修正的误报：
- 一个关键字下连写多个运动副（Yaris 等），原来读不出；
- `*PART_INERTIA` 定义的刚体部件被漏读（SID-IIs 等假人）；
- 用 `*CONSTRAINED_RIGID_BODIES` 合并后两侧是同一刚体（LSTC 假人），改报警告；
- 万向节轴小偏差（NCAC Econoline，|cos| ≤ 0.005），改报警告；
- 同轴的冗余转动铰（车门两侧铰链），不再报过约束；
- include 片段里的部件定义在别处，改报“无法核实”；
- 节点未定义时交给引用检查，运动副检查不再重复报错。

修正后仍报错误的 4 个 deck 都是真实问题：
- 一个本地齿轮减速器课程模型，以及公开的 NCAC Econoline：圆柱副或转动铰的 N1 与 N3 不在同一刚体上。用 R11 读取这两个模型，都报出 Warning 30485，节点对也一致。
- PIPER 的 2 个解析测试数据文件：转动铰节点对相距 26 mm。这是人造数据，不能计算。

无法核实的主要原因：`*SET_NODE_GENERAL` 集合（38 处）、部分节点刚体块读不了（14 处）、安全带单元（8 处）、include 片段（5 处）。这些情况只会不报，不会误报。

## 4. 未覆盖

- 运动副刚度 `*CONSTRAINED_JOINT_STIFFNESS`（限位、摩擦）只检查，不新建；
- 齿轮、齿条、滑轮、螺旋、等速、HARMONIC 只登记，不做几何检查；
- 节点刚体用 `*SET_NODE_GENERAL` 或 `_GENERATE` 定义时，读不出成员；
- 没有做 LSPP 原生重开核对（P11）。
