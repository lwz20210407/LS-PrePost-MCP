# ADR 0000：v0.5 开发决定

状态：已接受（2026-10-05）。范围以 tasks.yaml 为准。

- **D1**：执行以批处理为主（BatchEngine），常驻会话为辅；可见 GUI 只作观察模式。会话的触发方式由 E1-E5 实验决定。
- **D2**：后处理数值允许走 LASSO / LS-Reader，必须标注后端并与 LSPP 在回归语料上交叉校验；渲染与 LSPP 派生量走原生。
- **D3**：4.13 全量验证；4.10 跑回归子集；4.8 按能力探测尽力开放；4.11 排除。
- **D4**：v0.5 范围 = 本文件 release=v0.5 的任务。
- **D5**：在 restructure/v0.5 分支渐进重组；保留已验证原生命令、坑记录、结果数学、产物校验与逻辑测试。不推倒重来。
- **D6**：不回退到 Malps-del 作为基础，只借鉴其 cfile 模板白名单思路（即 T2 配方）。
- **D7**：仓库保持 Private，M4 退出标准满足后由用户决定是否公开。
