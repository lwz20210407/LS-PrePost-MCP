# Native common geometry measurement

`measure_gui_geometry(session_id, measurement, node_ids, units, axis="z", state=None, capture=False)` provides a common keyword/result interface. Modes: coordinates, distance, height, angle3, angle4, circle3. Keywords use reference coordinates and omit state. d3plot requires an explicit1-based state and native current-state coordinates. It targets the active model through unqualified node tokens; hardcoded model0 caused an observed keyword→result context failure and is not used.

Values come from native Measure/Identify command results. Circle centers come from the matching native message, preserving native text precision; host circle geometry is an independent check. Complete reference coordinates/topology/part membership and part visibility are verified unchanged. The requested result state and measurement/Identify overlays are retained; animation is stopped. Global axes0 and measurement scale1 are requested. Units are caller declarations; angle values are degrees. Height is an absolute/signed selected global delta component, distinct from total distance.

The native4.13.4 box checks cover XYZ, distance/components, negative signed height,3D3-node and4-node angles, radius/center, collinear rejection and axis-change recording replay. A private nontrivial d3plot checks current-state coordinates and distance using tail IDs outside the previous keyword's ID range; current model/state/geometry and original family hashes were checked. Driver: `tools/run_gui_measure_acceptance.py --workspace <private-directory> --executable <lspp> [--result <d3plot>]`.

Only the3D angle is interpreted. Projected angle values remain raw, since zero projection can be undefined. Circle requests require noncollinear points and exactly one matching center message. Missing/wrong layouts or source discrepancies fail. A known precondition rejection can restore readiness only after a completed response explicitly proves no query started and complete geometry/scope readback matches; timeouts/unknown requests are not replayed.

Optional native PNG is validated as a nonblank image, not OCR certification of all labels. Earlier failed setup/context probes remain local. All F4/F5 panel controls, local axes creation, mass/inertia, complete histories, arbitrary point/marker lifecycle and entity blanking remain in [common coverage](COMMON_OPERATIONS_COVERAGE.md).
