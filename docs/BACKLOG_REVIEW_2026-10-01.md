# 待开发与待增强清单（2026-10-01）

本次按代码、正式工具注册、原生验收结果和历次要求复核。代码基线 `795a354`；Service 操作 110 项，另有 4 个知识检索接口，最近自动测试 117 项通过。这些包含查询、准备、数学处理等接口，不能当作 LS-PrePost 功能覆盖率。包版本为 0.4.0 开发中，新增 GUI 验收主要限 Windows 4.13.4。

本清单列出缺口，不自行决定架构和版本。开发顺序受 [顶层设计](ARCHITECTURE.md) 和机器计划的依赖约束；首个实用版本必须让三条主流程共同收口，不能长期只扩展前处理。

状态：**增强**＝已有部分原生验收，范围需要扩展；**部分**＝有代码/替代后端/部分子功能，未形成完整流程；**待做**＝尚无合格实现。优先级是本次建议：P0 影响基础可用性；P1 高频工程操作；P2 扩展；P3 按用户要求后排。未重新执行同类 32 组私有结果，未公开任何私有模型或提取数据。

## 先确认已经具备的基础

- 41 个过滤器的解析/文件应用；7 个安装模板的展开与原生加载，不等于对应工况全部完成。
- 受管 GUI 连续操作、检查点、恢复、录制及参数回放；同一窗口原位平移/旋转。
- 原生重复节点合并、全部/局部壳法向反转、新增节点与三角/四边壳、节点/壳/部件重编号。
- 显式 ID/部件关联、盒/球/平面条件、全选/反选/清空、四种集合运算、原生 Buffer1–10。
- 原生壳 Element Quality 的 13 类指标、Keyword Check 报告；均含正常和错误反例。
- 受管操作录制与参数回放；13 步原始 cfile 转工作流并在同一 GUI 回放。
- 原始 command/cfile/SCL/应用内 Python/参数宏入口；部分原生应力/曲线及工程数学后处理。

上述验收范围见 [GUI 工作流](GUI_WORKFLOWS.md)、[原生程序](NATIVE_PROGRAMS.md)、[后处理合同](POSTPROCESSING.md)。每个完整模块都仍有下面的子功能缺口。

## 建议优先组成的交付批次

以下按领域分组，实际排期按顶层设计：先共用合同/质量门槛/按需访问，再推进网格和 Post，最后把两者纳入录制复用；不是先把本列表第一大类全部做完才开始 Post。

1. **基础可用性与规模**：A01–A05、A07。解决大模型、结果选择、显隐和质量门槛，再把现有流程固化成合成验收。
2. **选择 + 常用网格编辑**：B02–B05、C01–C06、D07。形成选区→改点/改单元→局部检查→定位失败→保存重开的完整流程。
3. **Post 高频工程任务**：E01–E09、E11、F03–F04。优先历史变量、ASCII/binout、积分点语义、原生曲线和统一出图。
4. **模型工程化**：D01–D05、D08–D11。材料/边界/接触/模板变成能用于实际工作的工况。
5. **版本与脚本扩展**：A06、G01–G08、H01–H05 随功能批次补齐；两种无 GUI 模式和几何仍遵循既定顺序。
