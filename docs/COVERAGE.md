# 资料覆盖不等于功能覆盖

项目目标是自然语言驱动的 LS-PrePost 常用前后处理完整流程。MCP 执行有类型的操作，Skill 组织前置检查、步骤、版本选择和产物验收。当前仍为早期开发版，**没有实现大部分手册功能，更没有实现所参考软件库的全部功能**。

## 资料转化情况

| 资料 | 当前实际利用 | 不能据此声称 |
|---|---|---|
| 官方 2026R1 在线指南 | 保存来源索引，阅读选定界面/操作章节，作为命令和语义依据 | 全部章节逐项实现、所有版本通用 |
| 官方教程 | 阅读并整理选定建模、网格、曲线与后处理步骤，形成候选验收流程 | 所有教程已有一键工具 |
| 官方 SCL/Python API 手册 | 对照数据类型、ID、状态、积分点、SCLBinout 定义实现部分接口 | 每个 API 都已包装或通过实机检查 |
| 本地标准 PyLSPP/SCL 示例 | 逐文件审查标准示例；借鉴查询、壳网格、数据导出、壳拉伸等方法 | 所有示例都已执行和移植 |
| 本地自定义脚本 | 按功能分类，记录错误和硬编码风险，选择性重写方法 | 直接执行原脚本或公开其内容 |
| 公开 MCP 项目 | 参考边界、工具形态和执行路线，独立实现当前执行核心 | 完整继承上游全部工具 |
| Hydrowelder 命令目录 | 归属与许可证保留的参考检索 | 命令条目就是已验证操作 |
| PyDYNA | Deck、弹性材料、节点集合、有限引用检查、限定分析模板 | 任意材料/接触/载荷/求解流程已接入 |
| LASSO / LS-Reader | 部分结果数据、ID 映射、独立数值对照 | 覆盖各库全部格式，或可冒充原生 LS-PrePost 操作 |

| 统一色标/层/平均、动画、对比报告 | 待扩展 | 尚无完整工作流 |
| 参数化完整工程案例 | 部分实现 | 位移加载平面壳板；球撞板、接触等完整案例未完成 |

## 开发完成标准

每个工作任务都应具备：可追溯来源、明确参数与假设、可执行工具、失败边界测试、相关版本原生验证、保存/重开或数值/图像检查、Skill 路由。资料阅读、命令检索、单次进程退出成功和重复运行同一套检查都不能代替这些条件。

优先选择能覆盖不同接口、单元类型、输出格式及失败条件的代表案例。私有工程算例只辅助开发，原始文件和所有相关提取结果不进入公开仓库。不给出没有明确分母的“功能覆盖百分比”。
