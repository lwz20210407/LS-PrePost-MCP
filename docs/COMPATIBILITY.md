初次通过长路径直接加载时出现读取器访问违规；GUI还会从偏好恢复工作目录。修正为在结果父目录以文件名加载，再回到任务目录后，4.10/4.13读到了同一样例的3234节点、2948单元、102状态。4.8通过将有界文件族复制到任务目录后使用SCL读回相同计数。SCL模式上限为256 MiB/1000文件，不改变原始文件。

上述256 MiB限制对应旧版 `inspect_d3plot_scl` 清单工具。新原生字段工具使用2 GiB有界暂存，批处理验收单组上限4 GiB，并在任务结束时清理本轮创建的输入副本。新批处理工作流的图像阶段需要已配置 Python 的4.13验证环境，不将其推广到所有旧版。

4.10的旧嵌入式Python向量数组在本次数据对照中出现错误值，因此该ABI上的原生向量工具主动失败，建议明确使用LASSO/LS-Reader后端。4.13的位移与速度在一个非零运动节点的三个状态上与LASSO一致；LASSO位移也与LS-Reader一致。这不是所有模型/所有变量的认证。

保存keyword还需处理部分构建给绝对输出路径添加临时前缀的问题：使用固定任务cwd和相对输出文件名，并检查新文件。不能仅因为进程退出0就宣布保存成功。

## 版本与解释器

外部MCP使用Python3.11+。应用内解释器由具体二进制决定；不能用版本名称推导唯一ABI。4.8以cfile/SCL作为初始兼容路径，未为了它强装已停止维护的Python3.6。

官方2026R1文档将 `runc=` 描述为真正无图形，图形操作不可用；`-nographics`仍可能依赖图形支持。当前运行器使用已测试的`c=`与对应模式，不假定4.8支持新参数。

`setpythonhome`会保存配置，只应在明确的安装配置步骤使用，不能作为每个任务的隐式副作用。本项目运行器不会自动更改兼容性、UAC或Python配置。
