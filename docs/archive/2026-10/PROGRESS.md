# 开发进度口径与实时面板

唯一数值台账是 [release_progress.json](release_progress.json)。从仓库运行 `python tools/progress_dashboard.py`，打开打印出的本机地址；面板每15秒重新读取台账。仅绑定127.0.0.1，只提供面板和进度JSON，不提供目录浏览、文件下载或修改入口。停止该进程后地址失效；不是外网网站。

进度 = 已通过验收项数 / 冻结验收项数。各项等权；部分实现不计完成。它不表示工时比例、LS-PrePost全部功能覆盖率、可靠性概率或交付日期。证据引用验证只检查台账完整性，不能自动证明原生功能正确。代码/CI/实机证据必须人工核对后更新。

2026-10-03 初次建表为18/30（60%）；用户当场强调 Entity Creation 属于核心前处理，补回此前未拆出的六项必要验收后，修正为18/36（50%），基线 `R1-20261003-36`。保留原始计数记录，完成项没有减少。今后范围变动必须显式记录，不删待办来提高比例。

新版包括通用框架、网格前处理、工程后处理、录制参数化、发布验收，以及[集合/约束/载荷创建](ENTITY_CREATION.md)。每项都展示实际边界，不把一个案例当成整个模块通过。4.8/4.10、两种无GUI、完整模板工况、CAD与高级模块另列后续路线，不混用验收比例。

当前工作和更新时间来自台账，不从页面刷新或时钟推断。没有新证据时数值保持不变；存在待办不等于某个后台进程正在开发。
