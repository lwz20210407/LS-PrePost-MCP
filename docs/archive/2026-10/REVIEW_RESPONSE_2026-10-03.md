# 外部架构评审的逐项处理

本记录核对用户提供的评审、最初调研方案、`adcde99` 代码基线和当前增量。项目目标保持 **LS-PrePost 通用前处理、后处理、原生脚本及参数化自动化**。霍普金森杆、材料试验、碰撞等属于可选案例，不作为核心产品定位。本文是处理记录，不用“工业级”“领域顶尖”或测试数量代替发布验收。

| 评审项 | 判断与证据 | 处理与剩余验收 |
|---|---|---|
| 工具数量和上下文负担 | 问题成立。全量服务一次暴露所有工具；评审中的精确工具数与当前代码不一致 | 新增可选 `compact` 模式：发现操作、读取单个严格参数定义、执行操作。完整模式保留兼容性。比较同一序列化方式的描述大小；实际模型选工具成功率仍须任务评测 |
| 40% 错选率、70% 上下文节约、1–2 天完成合并 | 未提供模型、任务集、tokenizer 或测量依据 | 不作为结论或承诺。工具表 JSON 字节数不等于输入 token，更不等于工程成功率 |
| 固定收敛到 16 个 action 工具 | 分组方向可参考，固定数量没有必要 | 按现有模块发现能力，单操作保留严格 schema 和原实现。不能用宽泛 `dict` 绕开校验，也不能把尚未实现的接触/报告功能列成可执行 action |
| GUI/批处理语义统一 | 采纳。已有 `operation_route`/`inspect_workflow` 实现部分统一 | 精简入口复用这套路由，显式 `direct`/`gui`、会话和参数。继续整合模型/选择/结果合同，保留原接口别名 |
| 失效会话或锁屏自动 fallback | 不采纳。内存模型、未保存编辑、选择和显示状态不等于磁盘副本 | 桌面检查提前到创建 native 请求和 busy 标志之前；拒绝后不生成待完成请求、不改为批处理、不重放未知修改。锁屏期间原生长任务是否继续另行观察，不能泛称“立即崩溃” |
| 控件 ID 漂移 | 采纳风险；现有菜单树已能枚举，部分旧调用仍固定 ID | 七类常用面板改成实际菜单路径解析。命令框保留已知 ID 作为配置提示，回退须满足所属进程/主窗口、可写、提示符、同父级只读历史框及唯一性。实测 4.13 命令 Edit 带 ES_MULTILINE，评审给的“只选单行 Edit”会排除真实控件 |
| 全模型连通性 JSON 瓶颈 | 对当前 `scoped_mesh_state` 的描述不准确：连通性逐单元参与摘要，并未整体返回 JSON | 全量扫描仍为 O(N)，SDK 调用和临时对象仍需测量；旧快照路线仍有 20,000 限制。不能把这些不同开销合成一个问题 |
| 二进制交换和分页 | 采纳，但不假设 SDK 一定提供稳定连续缓冲区 | 新显隐桥以分块二进制存储 `(type, user_id, active)`，返回格式/数量/字节数/SHA-256；外部校验后读取。已有网格分页/摘要继续保留。外部验证仍使用有界字典，不能称全流程零拷贝或百万单元秒级 |
| 接触管理薄弱 | 确认缺口，属于通用模型工程而非冲击专项 | 对应 D03：原生接触检查→问题实体→类型/厚度/间隙语义→受控修复→复查。自动接触与绑定接触不能统一套用“法向相反必须翻转” |
| 删除/侵蚀有效性 | 确认缺口 | 对应 E07/T04：逐状态物理 alive/deletion、显示隐藏、刚体及缺值分别表达；极值记录过滤策略及见证实体。DPF 合同适配不等于本机 Server 已验收；显示 active 不冒充物理掩码 |
| Include 组织保真 | 确认缺口，但不能称当前所有入口会默默压平 | 部分路径会明确拒绝 Include 重写。对应 D05：依赖树、相对路径、变换/参数作用域、指定叶文件增量编辑、原文件身份及原生重开比较；未完成前不宣称保真 |
| Skill 单体与专项 SOP | 主入口已分离多份按需参考文档，“所有内容都在一个大文件”不准确；任务 SOP 仍需加强 | 增补通用网格/后处理/参数化任务指引。专项力学配方保持可选，不新增默认霍普金森杆主线 |
| 固定沙漏能/总能量阈值、自动滤波 | 不作为通用默认规则 | 阈值、能量项、外功、接触/阻尼/侵蚀项和滤波标准必须有任务依据。异常可诊断，不凭两个经验比例普遍宣判仿真无效；未经请求不自动滤波 |

## 本批已落实与发布边界

- 标题与平均：保留模型标题，结果名采用已观察的 LS-PrePost 原生名称；去掉单位、实体类型、层和 `avg:0` 的自动后缀。自定义派生量使用明示的量名，不冒称不存在的原生名称。显示平均默认 `MinMax`；SCL 原始实体 CSV 保持原始采样，元数据分别记录两者。
- 显隐：标准 shell/solid/beam/element 的 hide/show/isolate/reverse/受管 restore。优化为较小集合或补集命令；在约 7,200 单元模型隔离 3 个单元时，不再逐个选择其余单元。`pall` 重置单元 Blank 的失败证据促使改用必要的 `+m` 恢复部件范围。
- 框架：可选精简 MCP 入口、动态菜单、受约束命令框定位、锁屏前置拒绝、二进制显隐读回。接口/合成测试、原生软件验收和未完成项分别登记。
- 未完成：通用接触闭环、物理侵蚀过滤、Include 保真、其余旧整模快照迁移、更多变量/菜单及跨版本/无 GUI 验收。

继续执行既有 [顶层设计](ARCHITECTURE.md)、[交付批次](DELIVERY_PLAN.md) 和三条工作流的退出标准，不再另建一套互相竞争的 v2 计划。阶段修复与推送不代表完整发布目标已完成。

## 对后续“正式落地版”的修正

后续评审与项目方向已一致，无需再次展开评价。纳入时保留以下精度：MinMax 是显示平均选项，关闭平均写作 `averaging="none"`，与色标范围独立；显隐属于功能域，不能与“原生已验证”并列成另一验收等级；按代码/合成、原生单项、完整流程、版本和规模分别记录证据。不预设 12–15 工具或 1,000 数值的强制分界，不把显隐标志二进制扩称完整几何传输，不将任意示例 SHA-256 当真实载荷摘要。SOP 与实现同步，稳定版本号依据退出标准确定。
