# 从首次需求到当前的开发总清单

目标：自然语言通过 **MCP + Skills** 操作 LS-PrePost，覆盖常用前处理、后处理、参数化、命令/脚本及连续 GUI 流程。资料目录、库安装、工具数量都不能充当功能覆盖率。以下回顾对话中明确提出的要求，并保留未完成项，不将愿景写成已实现。

状态：**验**=有相应后端的限定实机证据，仍看范围；**实现**=代码存在但验收不全；**部分**=仅子集或替代后端；**在做**=当前开发；**待做**=尚无合格实现。自动测试不等同于 LS-PrePost 实测。资料“吸收”以转化成工具、Skill、验证用例为完成条件。

最新补充：可见 GUI 最大化验收优先，随后才适配两种无 GUI 模式；围绕选择工具、Model、Mesh、Element Tools、Post 逐子模块覆盖，并扩大图文/代码/视频教程来源。阶段提交后继续开发，不把小批提交视为整个目标完成。

2026-10-01 已按当前代码重新展开 [待开发与待增强清单](BACKLOG_REVIEW_2026-10-01.md)，包括 20000 实体验证上限、结果模型选择、显示范围及工程质量门槛等底层缺口。本页保留最初请求的映射，细项以新清单编号 A–H 讨论。

## 优先级依据

2026-10-01 最新确认：先搭共用框架，重要业务是前处理、后处理、自动参数化，随后细化。曲线数据导出、曲线图/云图保存和动画文件导出明确属于核心后处理输出。按 [交付计划](DELIVERY_PLAN.md) 推进；本次已贯通流程预检、参数工况表、独立执行及汇总，不代表已补齐上述图像/动画缺口。
