Other snapshot-based merge/renumber/quality paths retain their documented limits.

## Workflow framework and explicit parameter studies

For a multi-step task, use `inspect_workflow` to see missing parameters, route/module ownership, dependency errors and deferred output bindings before execution. `run_workflow` enforces the same static preflight. A ready preview does not prove files, native build, current model or engineering validity.

For repeated preprocessing/postprocessing with different explicit parameters, use `run_workflow_sweep` with 1–20 `{id, parameters}` cases and optional named `{step_id, path}` scalar outputs. All cases are preflighted before the first runs; failures stop later cases. GUI studies require a recorded initial model or first `open_model`/`new_model`; preserve/checkpoint a dirty current model before changing it. Do not silently convert this into cumulative edits or retry an uncertain mutation. Reuse the visible mesh transform and declared-unit tensile recipes; report the child outputs and case summary. This is not solver scheduling, arbitrary branching or crash resume.

For curve PNGs use `export_gui_curve_plot` after extraction/engineering math. Bind the producer CSV artifact and explicit column names: `time,value` for scalar history; `displacement_mm,force_N` or `engineering_strain,engineering_stress_MPa` for tensile outputs. Supply matching declared units and short ASCII title/axis labels. It creates one new native XYPlot, preserves hysteresis row order and checks native float32 readback/PNG while retaining the original CSV. For overlays supply first `curve_label` plus up to9 `additional_curves` records {path,x_column,y_column,label,x_unit,y_unit}, with unique labels and matching units. Curves keep separate X grids/lengths; never imply resampling or unit conversion. Read `data.curves` and each plotted-N.csv for per-curve provenance; legacy numeric_verification/plotted.csv describe only the first curve. Recorded nested source paths can be parameterized. Arbitrary styling/curve operations remain pending. Use `visible_gui_relative_displacement_plot.json` for native selection→history→relative displacement→PNG.

For animation files, use `export_gui_animation`: native H264 MP4 starting at state1, increment1, through `last` inclusive (or full timeline). Specify fps and even resolution. Requires ffprobe/ffmpeg validators on PATH, without transcoding; missing dependencies fail before native work. The tool verifies ordered native frame/state evidence, complete decoding, count, rate, size and duration, and restores the current state. It leaves playback stopped with exported bounds. Current camera/fringe/visibility are retained without inferring field semantics; arbitrary start/step and GIF are not supported after failed native probes. Do not silently substitute playback control for file export. Managed workflow recording/replay is supported.

For timeout/crash recovery read [session recovery](../../../docs/SESSION_RECOVERY.md). `recover_gui_session` only reconciles correlated results; `requires_host_validation=true` leaves the model uncertain and is not permission to continue mutations. Do not resubmit the interrupted edit. Restore the trusted checkpoint explicitly, or inspect native evidence. `restart_gui_session` returns an existing replacement on repeat; if the replacement exited, recover that child to retain its latest saved model. Saved-model recovery does not certify arbitrary view/selection/macro restoration.

For visible keyword shell topology use `select_gui_shell_topology`: `adjacent` expands shared-node rings, while `propagate` uses shared edges and a local unoriented normal-angle threshold. Do not mix angle and ring parameters. Hidden entities/parts are boundaries, not an erosion mask. Its verified selection job can feed Segment creation and pressure workflows; see [topology contract](../../../docs/TOPOLOGY_SELECTION.md). Result/deformed propagation and arbitrary connection editing remain separate scopes.

For a directed existing-node replacement use `replace_gui_node(source_node_id, target_node_id, units)`: retain the target coordinate/ID, remove the source and update connectivity. Read [replacement scope](../../../docs/NODE_REPLACEMENT.md). It uses native Replace plus explicit Node LIST/Segment/SPC reference repair in a fresh copy and native reopen; report this mixed backend. Includes and unsupported node references reject; the complete-snapshot 20,000 limit still applies to this edit. Selection clears, part visibility is restored, and full scene preservation is not certified. Follow with native quality gates. After failure, recover the returned baseline rather than blindly rerunning the replacement.
