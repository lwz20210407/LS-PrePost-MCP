# Persistent automation routing

- Discover `list_installation_assets`, then `describe_installed_template` before parameterizing. Read unit/dependency labels. `apply_keyword_filter` selects keyword blocks; it does not switch the GUI filter. `instantiate_installed_template` creates a new deck. Template reopen is not per-card or solver validation; SALE/control fragments need a model seed for mesh loading.
- Start `start_gui_session`, show via `show_gui_session`, open a staged copy, then use `gui_session_action`. Node/part selections are explicit IDs. Choose `set_gui_display` and `set_gui_part_visibility` for common view/display controls. Animation submission has not received complete visual/end-state acceptance.
- Save `checkpoint_gui_session` before replacing meaningful state. `reset_gui_session` clears by opening a fresh empty deck; never send `new` to a live GUI. `restore_gui_checkpoint` replaces current state explicitly. PID/create-time/exe must still match.
- On timeout, inspect and call `recover_gui_session`. Never repeat an uncertain mutation. A read-only success cannot clear uncertainty. If recovery is unavailable, retain the request evidence and restore an explicit checkpoint only after the outstanding request is resolved.
- For new protocol-3 GUI sessions use `translate_gui_nodes` / `rotate_gui_nodes`; legacy GUI action names route to them. These edit the same visible instance, with coordinate/topology readback. The v0.3 `native_checkpoint_batch_reopen` path remains for older bridge sessions only. Do not invoke a hidden instance when the user requests visible GUI validation first.
- Use `select_gui_entities` for current keyword-model IDs, part membership, whole/clear/inverse. `select_gui_nodes_by_box` and `select_gui_nodes_by_sphere` evaluate reference coordinates, then select and verify native IDs; they are not camera-space picking. Solid/beam selection still needs native coverage.
- Use `renumber_gui_entities` for all nodes, shells or parts in a visible GUI. Keep reference checks enabled for supported standalone decks. Verify the returned native ID mapping and scoped reference report; this does not certify every keyword card or the solver. Offset, partial renumber and other versions remain separate work.
- Use `combine_gui_selections` for explicit ID union/intersection/difference/xor. Use `select_gui_nodes_by_plane` for signed reference-coordinate distance (band/positive/negative). These drive and verify native selection; they do not reproduce screen-space mouse picking.
- Use `save_gui_selection_buffer` with explicit node/shell/part IDs and slot 1–10, then `load_gui_selection_buffer` to replace the selection. Save verifies a native clear/reload round trip. Buffers belong to the managed session and exact model fingerprint; resave after model changes. Raw/manual replacement is detected by ID readback, not silently accepted. All these tools are workflow/recording actions.
- Use `check_gui_shell_quality` for actual native Model Checking shell metrics and explicit thresholds. Read `verification.passed_checks`: successful execution is not proof of acceptable mesh. Preserve backend/units/native display precision; no corresponding topology is `not_applicable`. Percentages retain native denominator semantics, not topology-subset normalization. This is separate from `inspect_gui_mesh_quality` geometry math and from Reference Check.
- Use `check_gui_keywords` for actual native Keyword Check and its exported report. Inspect warnings/errors/unreferenced/undefined separately. It explicitly excludes contact checking and never cleans/deletes data. Completed checks with findings are not clean-model or solver certification. Contact checks and automatic repairs remain separate work.
- `inspect_gui_menu` discovers actual menu paths and command IDs for the current owned build; menu inventory does not certify those functions. Do not infer that 448 tree entries means 448 implemented actions.
- Use `merge_gui_duplicate_nodes` for native Duplicate Nodes and `reverse_gui_shell_normals` for all shells or an explicit `shell_ids` subset; unselected connectivity is checked. New nodes/elements can be imported natively with `create_gui_nodes` / `create_gui_elements`; this does not cover every edit-panel option. `inspect_gui_mesh_quality` reads native memory then performs geometry math, not native Model Checking. Inspect returned scope and unsupported topology. Save/reopen and reference checks remain necessary.
- GUI sessions use a private configuration copy via LSTC_FILE, preserving existing consent/Python settings and redirecting task paths. `show_gui_session(maximize=true)` supports visible inspection; use temporary `keep_on_top` only when needed. Locked desktops block GUI input. `restart_gui_session` restores a saved checkpoint/staged source after the owned process exits, without replaying uncertain mutations.
- Selection/inspection transactions no longer export two full keyword checkpoints. They preserve prior checkpoint/dirty metadata and verify geometry; edits still create pre/post checkpoints. Inspect transaction_kind/checkpoint_created instead of assuming every result saved a new model. Full mesh snapshot/20000 limits remain until the later scale work is verified.
- `transform_mesh_deck`, `merge_duplicate_mesh_nodes` and `inspect_mesh_quality` use PyDYNA/geometry math, optionally followed by native reopen. They must never be reported as native Duplicate Nodes/Model Checking. Unsupported topology/references require another implementation or manual review. Coordinate-only transforms do not rotate loads/material axes.
- Recording recipe captures managed MCP calls only. `start_session_recording` snapshots the baseline; `stop_session_recording` preserves recipe and raw native cfile separately. Manual GUI changes may exist only in the raw file. `parameterize_workflow` binds explicit argument paths; it preserves review gates. `run_workflow` stops on failure. `import_command_recording` recognizes a bounded subset; unknown/opaque commands block execution.
- Workflows now distinguish successful execution from successful checks. Native shell/keyword checks and scoped mesh/reference checks require explicit true verdicts by default. Use step `quality_policy="report_only"` only when the task intentionally permits findings, then define explicit `checks` for allowable counts/limits; execution failure and those checks still stop. Missing/null/invalid verdicts never count as pass. Do not set report_only simply to get past a failure.
- Step checks use strict result paths and eq/ne/lt/le/gt/ge or is_true/is_false/is_null/not_null; numeric limits can be `$param`. Parameterize thresholds with `section="checks"`. Energy screens need explicit exceedance/undefined-row predicates; passing a screening threshold does not certify physics. Read `failed_step`, `skipped_steps`, `gates.json` and saved baseline checkpoints. No automatic replay/rollback is performed.
- Managed GUI workflow recording preserves the applied quality_policy and resolved checks. Finish an executing workflow before stopping its recording. Recorded failed gates require review; never remove conditions just to make replay finish. Parameterized policy replay was checked in visible 4.13.4 with both allowed and blocked edits, not across all versions or arbitrary manual/mixed-backend recordings.
- Raw cfile import now covers explicit/whole/inverse selection, native buffer save→clear→load, selected translation/normals and shell quality checks. Dynamic whole/buffer IDs use verified result bindings. Clear before changing targets. Model-qualified IDs need explicit `recorded_model_index` matching every suffix; never silently strip `/0` or guess a multi-model mapping. Unsupported selection context remains `needs_review`.
- `native_tensile_postprocess`: specify force database/entity/component, top/bottom nodes, displacement component, area, gauge length and units/signs. Source curves come from native LS-PrePost; engineering calculations use explicit math. Alignment is linear within the shared time interval. Area unit is length squared. True conversion, when requested through `build_tensile_curves`, assumes uniform incompressible pre-necking deformation.
- `native_energy_postprocess` reads named GLSTAT quantities using native SCLBinout, then computes a screening report. Missing requested energy fails. Omitted hourglass energy stays undefined, never inferred zero. Zero denominators are null. Neither KE/IE thresholds nor a partial budget certify quasi-static behavior or complete energy conservation.
- Keep all private source/result/derived data local. Prefer synthetic complete-workflow checks to re-running many equivalent private cases. See `docs/WORKFLOWS_v0.3.md` for concrete verification scope and remaining gaps.
