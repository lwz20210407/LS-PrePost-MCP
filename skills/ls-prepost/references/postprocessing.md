# Result routing

For alive-only element statistics, inspect `inspect_result_validity` and pass `validity_policy="alive"` to native or reader field/stress exporters. Native values still come from SCL; the additional physical mask is explicitly LASSO and needs the results extra. Preserve a user's native-only constraint: if no auxiliary reader is permitted, report this limitation. The compatibility default `raw` does not remove deleted entities. MDLOPT2 positive material codes mean present, zero means deleted; Blank and part visibility are not physical validity. Missing masks/ambiguous adaptive IDs fail; an all-deleted request returns a header-only CSV and null extrema, not zero stress. Read [validity scope](../../../docs/RESULT_VALIDITY.md) before making an alive-only claim. The current native acceptance is solid 4.13.4; static solid PNG/CSV has native physical-mask evidence; the native Movie interface rejects physical masks; use the separate per-state field animation route when its scope matches.

For an alive-only static solid/shell cloud plot, pass `validity_policy="alive"` to `render_gui_field`; it verifies native hiding of deleted entities and exact CSV membership, and uses retained values for bounds. An all-deleted scope rejects a meaningless PNG. It retains the requested scene/Blank. For physical-field video use `export_gui_field_animation` with explicit states/fixed bounds: native PNGs, explicit FFmpeg encoding, all alive entities in selected parts, manual Blank/state restored afterwards. Record view and field setup before the movie for replay; see [field movies](../../../docs/FIELD_MOVIES.md).

For a named native cloud plot use `render_gui_field`, not a guessed numeric fringe code. Require explicit entity domain, state, quantity, unit label and layer/point; optional part IDs and fixed color bounds. Same native arrays produce CSV and PNG with no nodal averaging. It leaves requested state/parts/fringe, stops animation and clears general selection. The results extra validates staged-header availability only; values remain native. Incompatible headers and missing variables fail. Solid Mises/pressure/mean stress and node displacement magnitude have native evidence; nontrivial shell/tshell layers and per-material/deleted validity remain unverified. See `docs/NATIVE_MEDIA.md`. Render every state with the same definition before custom-field movie export; missing coverage is an error.

Native SCL fields/stresses and LASSO scalar/stress exports now include `field_spec` in parameters and returned data. Read its backend, user-ID/state selection identity, sampling kind, frame, averaging, validity and transformations before comparing results. Native MID/INNER/OUTER, solid default selector 0, and reader stored slot 1 are not automatically equivalent. Nodal native extraction uses the legacy `mid` argument only as default/no-layer; numeric node integration points are rejected. Unit labels are retained with dimensional_validation=false, not inferred conversions.

Use the native route when requested. `extract_native_stress` obtains all six components and Mises from native SCL; its derived triaxiality/Lode calculation is explicitly labeled Python mathematics on native data. Inspect the native-Mises agreement rather than inferring correctness from a valid CSV.

For visible selected-node histories, bind `select_gui_entities.verification.selected_ids` to `extract_node_history.node_ids` inside a GUI workflow. Add explicit `curve_components` and `time_unit` to export scalar curves for `combine_history_curves`; inspect each curve's node/component/quantity/unit metadata. The shared template `examples/workflows/visible_gui_relative_displacement.json` computes first minus second in sorted selected-ID order, not a gauge projection. Supply exactly two IDs, increasing states and explicit unit labels. At most 100 scalar curves; no position magnitude. Extraction stops animation and confirms restoration of the original state; it does not resume playback. Native 4.13.4 passed the two-component workflow and position/reference/displacement identity check. Keep all private input and derived evidence local.

For visible element/nodal SCL fields, use `gui_session_action(action="extract_native_fields" or "extract_native_stress")`, with existing arguments except `path`. A GUI workflow routes these two actions into its current result session automatically; omit `path` there too. Bind verified selected IDs, explicit states and sampling; require `data.session_context_preserved`. This reuses the batch parser and Mises check with native SCL, restores state and checks geometry/selection/part flags, and starts no extra LSPP. Solid stress, six strain components and effective plastic strain passed representative 4.13.4 testing. Shell layers/tshell/beam, alive masks and arbitrary history-variable interpretation are not newly certified. This GUI verification requires embedded Python and the 20000-entity snapshot bound.

Use `examples/workflows/visible_gui_selected_stress.json` for selected-solid stress. Its managed display/selection/stress recording was parameterized by states and replayed successfully after reopening the staged result; the context check survived recording. Raw SCL text recording alone is not equivalent to this typed recipe.

Use `convert_history_units` for explicit single-entity scalar CSV conversion, or supply `source_units=[{time,value},...]` and output `time_unit` to `combine_history_curves` for conversion before alignment. Require declared units; never guess from model values. The unit contract checks mechanical dimensions, preserves exact scale fractions, and rejects unsupported/affine units, overflow/underflow and collapsed times. Legacy combination without source metadata is explicitly `assumed_shared`, not dimensionally verified. Use `examples/workflows/declared_unit_tensile.json` to normalize force and relative displacement before engineering stress/strain/work; supply area in mm², gauge in mm and explicit signs. See [unit contract](../../../docs/UNIT_CONTRACTS.md).

Tensor order: xx, yy, zz, xy, yz, xz. Tension positive. Shell/solid integration point must be explicit; no averaging is implied. Mises=sqrt(3J2), triaxiality=mean/Mises. `lode_angle_parameter=1−6θ/π` is +1 in uniaxial tension; `lode_parameter=(2σ2−σ1−σ3)/(σ1−σ3)` is −1. Preserve these different names and the returned definitions. Hydrostatic ratios are null/empty, not zero.

Native solid point selectors 2..8 currently reject: real 4.13.4 SCL evidence showed point 8 returning point 1. Do not replace the requested point with `mid`/1 or silently switch to a reader. Explicit reader stored-point extraction is a separate option; the native adapter remains unfinished. Native shell point selectors have separate bounded evidence.

Native ASCII uses database-specific UI component numbers, not d3plot fringe/ntime codes. Inspect installed-version documentation and the tested scope. Contact master/slave selectors and ELOUT integration points need dedicated adapters; do not append arbitrary tokens to existing tools.

For optional reader extraction, call `inspect_result_fields`, then select actual user IDs, states and every trailing stored-axis index. History-slot interpretation requires the material/version/output definition. A missing field cannot be reconstructed by naming it. No generic native history-variable route is certified yet.

Native batch acceptance samples three geometry records per entity type for histories, scans whole fields for extrema, exports available supported ASCII curves and renders a native image. It preserves native returned values, including deleted entities/rigid zeros unless documented otherwise. All checks and source copies belong to owned job directories. Keep private engineering results out of Git and public reports.

See the repository [full contract](../../../docs/POSTPROCESSING.md) for supported tools and remaining gaps.
